# Scientific validation resources

This directory contains the reproducible scientific-validation study and its
machine-readable results.

  practical interpretation, expected false positives, runtime, and limitations.
- **Maintainers and reviewers:** read
  [`MAINTAINERS.md`](MAINTAINERS.md) for reproduction instructions, snapshot
  policy, threshold decisions, regression findings, and future work.
